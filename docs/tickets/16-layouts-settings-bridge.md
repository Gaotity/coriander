# 16 — Layouts + settings bridge

**Parent spec:** [docs/spec/mvp.md](../spec/mvp.md)
**Blocked by:** 08
**Status:** ready-for-agent

## What to build

iPhone landscape, iPad full-size and floating-keyboard Layout adaptations; plus the App Group user-defaults bridge that carries UI-layer settings from the Container App to the keyboard.

## Acceptance criteria

- [ ] iPhone portrait/landscape layouts adapt
- [ ] iPad full + floating presentations adapt
- [ ] A defaults value set in the app is read by the keyboard
- [ ] No layout regressions on compact sizes
