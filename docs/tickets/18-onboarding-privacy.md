# 18 — Onboarding + seed progress + privacy screen

**Parent spec:** [docs/spec/mvp.md](../spec/mvp.md)
**Blocked by:** 07
**Status:** ready-for-agent

## What to build

Guided onboarding: walk through enabling the keyboard in iOS Settings; first-launch seed progress UI; privacy explanation screen shown before any optional permission (no network ever; Full Access only for local writes).

## Acceptance criteria

- [ ] Fresh install: guided enable-keyboard flow end-to-end
- [ ] Seed progress visible on first launch
- [ ] Privacy screen precedes any permission request
- [ ] Copy matches actual behavior (verifiable claims)
